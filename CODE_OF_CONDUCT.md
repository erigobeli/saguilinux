# Código de Conduta

Este projeto adota o [Contributor Covenant 2.1](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/). Em resumo:

- Seja respeitoso e acolhedor com todas as pessoas, independentemente de experiência, identidade ou origem.
- Critique ideias e código, nunca pessoas. Perguntas de iniciante são bem-vindas — este é um projeto para aprender.
- Não são aceitos assédio, ofensas, ataques pessoais, divulgação de dados privados de terceiros ou qualquer conduta inadequada num ambiente profissional.

Problemas podem ser relatados ao mantenedor pelo canal [@EliRigobeliAI](https://www.youtube.com/@EliRigobeliAI) ou por uma issue marcada como "conduta". O mantenedor pode remover comentários, commits ou participantes que violem este código.

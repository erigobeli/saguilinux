# Segurança

O Sagui Linux é um **projeto educacional** e **não recebe atualizações de segurança**. As versões publicadas usam os pacotes do LFS/BLFS 12.4 (setembro de 2025) e as senhas do modo live são públicas.

- **Não use** o Sagui Linux como sistema principal, em servidores, para dados sensíveis ou operações bancárias.
- Se encontrar um problema de segurança **nos scripts deste repositório** (por exemplo, algo que exponha o computador de quem compila), abra uma issue descrevendo o problema sem incluir exploração detalhada.
- Vulnerabilidades em pacotes de terceiros (kernel, Firefox, glibc…) devem ser relatadas aos respectivos projetos.

Download

Duas edições, ambas em formato live: você grava a imagem (ISO) num pendrive ou abre numa máquina virtual e o sistema roda direto dela, sem instalar nada no computador.

Antes de baixar, entenda o que vai acontecer O sistema roda inteiro na memória RAM. Tudo o que você criar, baixar ou alterar enquanto usa o Sagui Linux desaparece quando desligar ou reiniciar — inclusive arquivos que pareçam salvos na pasta pessoal. Gravar a ISO no pendrive apaga tudo o que havia nele. Leia os cuidados antes de testar.

Live CD e live USB: como funciona

Live USB (pendrive)

A forma recomendada. Você grava a ISO num pendrive com o balenaEtcher e liga o computador por ele. Pendrive de 1 GB (terminal) ou 2 GB (desktop) ou mais.

Live CD / máquina virtual

A mesma ISO funciona como CD/DVD virtual no VirtualBox, VMware ou QEMU — o jeito mais seguro de experimentar, sem mexer no computador.

BIOS e UEFI

As ISOs são híbridas: dão boot em PCs antigos (BIOS/Legacy) e novos (UEFI). O Secure Boot precisa estar desligado — as imagens não são assinadas.

Ao ligar pelo pendrive, um pequeno programa de inicialização (initramfs) procura a mídia do Sagui, monta o sistema compactado (squashfs, só leitura) e coloca por cima uma camada gravável na memória RAM (overlayfs). Por isso o sistema funciona normalmente — dá para criar arquivos, abrir programas, mudar configurações — mas nada disso fica no pendrive nem no disco. Ao desligar, a RAM é apagada e tudo volta ao estado original.

Requisitos

  • Computador de 64 bits (x86_64 / amd64) — Intel ou AMD.
  • Memória: 2 GB (desktop) ou 1 GB (terminal); com 4 GB o desktop fica confortável.
  • Vídeo: funciona em praticamente qualquer placa pelo modo genérico. Intel antigas, NVIDIA (nouveau) e máquinas virtuais têm driver próprio; AMD/Radeon e Intel recentes usam renderização por software nesta versão.
  • Rede: só cabo (Ethernet). Wi-Fi não é suportado.

Código-fonte

O Sagui Linux é feito só de software livre. Como pedem as licenças GPL, junto de cada ISO publicamos o código-fonte completo de todos os pacotes que estão nela — os mesmos tarballs originais usados na compilação, inclusive as dependências baixadas automaticamente durante o build (crates do Rust) — e os scripts de build exatos (incluindo a configuração do kernel) estão no repositório do GitHub. Com eles, qualquer pessoa pode conferir e reconstruir o sistema.

Conferir o arquivo baixado

Compare o SHA-256 do arquivo com o publicado acima. Se for diferente, o download veio corrompido — baixe de novo.

# Windows (PowerShell)
Get-FileHash .\sagui-linux-2.0-x86_64.iso -Algorithm SHA256

# Linux
sha256sum sagui-linux-2.0-x86_64.iso

# macOS
shasum -a 256 sagui-linux-2.0-x86_64.iso
